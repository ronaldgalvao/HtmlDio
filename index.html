Listas

Listas podem ser ordenadas ou não-ordendas, no caso de ser lista ordenada será utilizada a tag <OL>. Em caso de ser lista não-ordenada será utilizada a tag <UL>, e um exemplo de lista não-ordenada é o que utilizamos no nosso súmario no ínicio desse site.

Tags

Tags são a forma de escrever elementos em HTML, abrimos a tag para adicionar esses elementos que podem ser textos, imagens, vídeos, links, etc... e após adicionar o conteúdo desejado precisamos realizar o fechamento da tag que foi aberta anteriormente.

Atributos

Atributos em HTML definem as características adicionais dos elementos, como "src" quando queremos trabalhar com imagens, href para links e class para identificação dos elementos e suas estilizações no CSS.

Links

Link é a forma de realizar navegação, podendo ser para outras páginas ou para algum elemento da própria página. Conseguimos definir o atributo target que pode ser blank ou self, onde blank identifica a abertura do link em outra página e self dentro da própria página.
